# Mood board artifact: source

The source of the visual mood board published as a Claude artifact: https://claude.ai/artifact/7RkR5Dg45Jn9JNtTA55nMj. The artifact is private to Rufus's claude.ai account, so this folder is the durable copy. Open `index.html` in a browser to view it.

The six page renders from the unpublished Awami Conscious Food book (`awami-p1`, `awami-p8`, `awami-p12`, `awami-p17`, `awami-p20`, `awami-p23`) and the cover wash are deliberately not in this repo, because the repo is public and the book is not released. The Direction E section of the page therefore shows broken images here. The cut-out paintings (`awami-*.webp`) are already published on the site.

To republish or edit: use the Artifact tool with `index.html` and this `img/` folder as the supporting files. The notes behind it are in `../moodboard.md`, and the decision it led to is in `../design-direction.md` section 7.
